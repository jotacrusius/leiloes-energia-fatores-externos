# CLAUDE.md
There is no build system, package manager, linter or test suite. All CSS is inline in a `<style>` block and the page uses no JavaScript. To preview, open `index.html` in a browser.

## Content conventions

- Write all page text in pt-BR, in a technical but accessible tone.
- The page cites specific Brazilian legislation (e.g. Lei nº 10.848/2004, Decreto nº 5.163/2004, Lei nº 14.052/2020, Lei nº 14.120/2021, Lei nº 15.269/2025, REN ANEEL nº 1.030/2022). Regulatory accuracy matters: verify any new or changed legal reference and keep the format "Lei nº X/AAAA".
- Sector acronyms (MME, EPE, ANEEL, CCEE, ONS, ACR, ACL, CCEAR, PLD, CMO, MRE, GSF, ICB, CVU, TUST/TUSD) are introduced in the earlier sections and then used freely.
